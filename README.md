# linkit courses

Kursmaterial der Lernplattform **linkit courses** von linkit e.V., der Hochschulgruppe für Data Science und Industrie 4.0 am KIT. Jeden Kurs kann man das ganze Jahr im eigenen Tempo machen. Das Abschlussprojekt entsteht zu zweit und wird von einem linkit Expert abgenommen.

| Kurs | Inhalt |
|---|---|
| [AI Engineering: von LLMs zu Agenten](ai-engineering/) | 15 Module von Python und NumPy über Transformer, RAG und Tool Use bis zu Agenten, Evaluation und Sicherheit. Notebooks für Google Colab mit der KI-Toolbox des KIT. |
| [Data Science 1](data-science-1/) | Einstieg in Data Science an Werksdaten der Nordwerk GmbH: pandas, SQL, Statistik, Regression und Klassifikation bis zu Zeitreihen, A/B-Tests und kausaler Inferenz. 15 Module, im Pilot fertig sind Modul 0 bis 2. Notebooks laufen im Browser oder in Colab. |

## Testversion der Plattform

Die Pilotversion mit vertonten Lerneinheiten, Tutoriumsblättern und Notebooks läuft über GitHub Pages: **https://juliankunz18.github.io/linkit-courses/** (AI Engineering) und **https://juliankunz18.github.io/linkit-courses/ds1.html** (Data Science 1).

Der Ordner [`docs/`](docs/) enthält die gebaute Seite. Sie lädt nichts von fremden Servern: Schriften (JetBrains Mono, OFL), Formelsatz (MathJax, Apache 2.0) und die Python-Laufzeit für den Browser (Pyodide, MPL 2.0) liegen mit im Ordner. Feedback aus dem Pilot geht als Text über die linkit-WhatsApp-Gruppe an Julian.
