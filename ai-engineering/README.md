## So arbeitest du mit den Notebooks

1. Link anklicken, das Notebook öffnet sich in Colab (Google-Konto nötig).
2. **Datei → Kopie in Drive speichern.** Sonst ist deine Arbeit nach einer Pause weg.
3. Einmalig in Modul 0: Auf [ki-toolbox.scc.kit.edu](https://ki-toolbox.scc.kit.edu/) einen API-Schlüssel erstellen, in Colab links auf das Schlüsselsymbol klicken, ein Secret mit dem Namen `KIT_TOOLBOX_KEY` anlegen und den Notebook-Zugriff einschalten. Der Schlüssel gehört nie in den Code.
4. Zellen von oben nach unten ausführen. Nach jeder Aufgabe zeigt ein Selbsttest ✅ oder ❌.
